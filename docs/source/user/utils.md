# Cula Utils

The cula utilities, provided in the `libcula/utils.h` header consists of things like `cula_container_of`,
`cula_signal_add`, `cula_list_init`, `cula_list_remove`, and so on. This page will serve to document
all of it.

These utilities you see here are from wayland and a renamed version of `wl_container_of`, `wl_singal_add`, and 
so on. You can read through [Wayland Appendix C.](https://wayland.freedesktop.org/docs/html/apc.html#Server-structwl__list)
to see use cases of `wl_list` and the said.

DBus¶

Data Types¶

struct cula_dbus¶
struct cula_dbus {
    struct cula_service *service;
    struct cula_context *context;
    enum cula_dbus_type bus_type;
    enum cula_dbus_status status;
    sd_bus *bus;

    struct {
        cula_list_t calls;
        cula_listener_t destroy;
        struct cula_dbus_poll *poll;
    } DBUS_INTERNAL;
};

Represents a D-Bus connection service instance.

struct cula_dbus_call_ctx {

    struct cula_dbus *dbus;
    const char *destination;

    const char *interface;
    const char *method;
    sd_bus_message *message;

    sd_bus_slot *slot;
    sd_bus_message *reply;

    struct {
        cula_signal_t result;
    } events;
};

API¶

struct cula_dbus *cula_get_or_create_dbus(struct cula_context *ctx, enum cula_dbus_type bus_type)¶

Create a new D-Bus service instance attached to a context.

Parameters:

  • ctx – The cula context running the event loop.

  • bus_type – The type of bus (“system” or “session”).

Returns:

struct cula_dbus * Newly allocated D-Bus service or NULL on failure.

struct cula_dbus_call_ctx *cula_create_dbus_call(struct cula_dbus *dbus, const char *dest, const char *path, const char *iface, const char *method, const char *types, ...)¶

Construct a dbus call context.

Parameters:

  • dbus – The cula dbus to make the call to.

  • dest – Destination of call (e.g. “org.freedesktop.UPower”).

  • path – Path of call (e.g. “/org/freedesktop/UPower/devices/battery_BAT0”).

  • iface – Interface of call (e.g. “org.freedesktop.UPower.Device”).

  • method – Method of the call (e.g. “Refresh”).

  • types – Types.

  • ... – Other params.

void cula_call_dbus(struct cula_context *ctx, struct cula_dbus_call_ctx *call_ctx, enum cula_dbus_call_ctx_type type)¶

Make a call to the dbus with the specified call context.

Parameters:

  • call_ctx – The call context with call info.

  • type – The type of call to make.

void cula_destroy_dbus_call(struct cula_dbus_call_ctx *call_ctx)¶

Destroy a dbus call.

void cula_destroy_dbus(struct cula_dbus *dbus)¶

Destroy a D-Bus service instance and clean up resources.
